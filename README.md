# obstacle_avoiding_car
An Obstacle Avoiding Car is an autonomous robotic vehicle designed to detect and avoid obstacles in its path without human control. The system typically uses an ultrasonic sensor to measure the distance between the car and nearby objects.

A microcontroller, such as an Arduino, processes the sensor data and controls the motors accordingly. When an obstacle is detected within a specified distance, the car automatically stops, changes its direction, and continues moving along a clear path.

Key Components
Arduino or other microcontroller

Ultrasonic sensor (HC-SR04)

Motor driver module

DC geared motors

Robot chassis and wheels

Battery/power supply

Servo motor for sensor movement

Working Principle
The ultrasonic sensor continuously measures the distance to objects in front of the vehicle. If the measured distance is safe, the car moves forward. When an obstacle is detected, the microcontroller instructs the motor driver to stop the car and turn it toward a direction with fewer obstacles.

Applications
Educational robotics projects

Autonomous vehicles

Smart transportation systems

Industrial robots

Surveillance and exploration robots

Overall, an obstacle-avoiding car demonstrates the basic principles of robotics, sensors, automation, and autonomous navigation, making it a useful project for learning embedded systems and intelligent vehicle control.
